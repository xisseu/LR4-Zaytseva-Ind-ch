Template Name: SecureTrust Container - Banking Microservice with Protection against UBI.021 Threat
Usage: To install, clone the repo, run pip install -r requirements.txt, then python manage.py migrate and python manage.py runserver 0.0.0.0:8080. Open https://workspace.your-username.replit.app. Features: enclave attestation (trusted status), account balances (ACC1-ACC3), income/expense statistics, transfers (with category and type), transaction history, and UBI.021 security check. API endpoints: GET /api/attestation, GET /api/balance/<account>, GET /api/transactions, POST /api/transfer, GET /api/stats, GET /api/health.
